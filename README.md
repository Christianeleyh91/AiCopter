# AI Copter

AI Copter is a bilingual interactive showcase for two connected computer-vision research projects:

- **Simorgh Face for Webcam** — local face recognition, encrypted identity templates, quality control, temporal voting, and active liveness.
- **Drone Vision in Unreal Engine** — rendered-character recognition, live camera visualization, face-guided tracking, and depth-based obstacle avoidance through Cosys-AirSim.

## Technology

YuNet, SFace, MediaPipe, OpenCV, Python, Unreal Engine 5.8, Cosys-AirSim, React, TypeScript, and Vinext.

## Run locally

```powershell
pnpm install
pnpm run dev
```
